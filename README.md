# UAV Leaflet Dispenser · 无人机挂载式单张纸页分离投放装置

面向中型多旋翼无人机的挂载式**单张纸页分离投放装置**项目文档。装置以打印机式搓纸分纸实现单张分离，配主动出纸快门遮蔽巡航，借导纸通道使纸张切入旋翼下洗流减小落点漂移，并由微控制器实现单张 / 连续 / 飞控联动多模式投放时序控制。

本仓库收录该项目的完整技术文档与专利交底书源稿（Markdown）。

## 技术路线

以打印机式**搓纸分纸**实现单张分离（过纸间隙 d≤h≤1.5d），配**主动出纸快门**遮蔽巡航，借**导纸通道**使纸张切入旋翼**下洗流**减小漂移，并由微控制器实现**单张 / 连续 / 飞控联动**多模式投放时序控制。

## 主要待确认事项
